# Development roadmap

## Stage 1 — Local prototype
- [x] Godot 4 project and generated 3D training range
- [x] Basic first-person movement and aiming
- [x] Hitscan shooting and destructible targets
- [x] Initial touch controls for Android
- [ ] Open and run in Godot editor; fix any engine-version issues
- [ ] Test touch behavior on a real Android device

## Stage 2 — Shooter feel
- [ ] Weapon recoil, reload, ammo and hit feedback
- [ ] Jump polish, sprint and crouch
- [ ] Audio cues, footstep effects and settings
- [ ] Better original models, materials, animation and UI

## Stage 3 — Multiplayer
- [ ] Decide authoritative server architecture and hosting budget
- [ ] Player identity and lobby/room flow
- [ ] Server-validated movement, damage and eliminations
- [ ] Reconnect handling, latency compensation and abuse mitigation
- [ ] Test with multiple clients on different networks

## Stage 4 — Battle-royale loop
- [ ] Large map and safe-zone logic
- [ ] Loot, inventory, weapon pickups and healing
- [ ] Match phases, win/lose screen and spectator flow
- [ ] Bot fallback and network performance profiling

## Stage 5 — Android release
- [ ] Android export templates and export preset
- [ ] Configure app ID, orientation and permissions
- [ ] Sign release builds securely
- [ ] Test low/mid-range devices, thermal behavior and battery use
- [ ] Privacy policy, crash reporting and release checklist
